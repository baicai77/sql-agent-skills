# SQL Agent Skills

两份面向 AI 编程助手的中文 SQL 技能：一份用于编写和审查查询，一份用于交付 Hive 数仓落表脚本。它们是 Markdown 规范，不连接数据库，也不会自行执行 SQL。

| 技能 | 何时使用 |
| --- | --- |
| [simple-direct-sql](simple-direct-sql/SKILL.md) | 编写或审查 SELECT 查询，核对结果粒度、关联扇出、版本去重与空值语义。不限于 Hive。 |
| [hive-etl-sql-template](hive-etl-sql-template/SKILL.md) | 编写或审查 Hive 建表、分区覆盖和日调度脚本。涉及查询体时同时使用基础技能；纯 DDL 可单独使用。 |

## 使用

将需要的技能目录完整复制到客户端支持的 skills 目录，保留 `<技能名>/SKILL.md` 结构。如果客户端不支持技能发现，也可以直接让助手读取对应文件。

例如：

- **查询审查：**「使用 `simple-direct-sql` 审查这段查询。一笔订单允许分多次退款，检查支付金额是否因关联被重复累计。」
- **Hive 落表：**「使用两份技能生成按日覆盖的门店交易汇总脚本。仅保留当天有支付的门店；如果输入版本、退款归属或目标分区范围不明确，先向我确认。」

Hive 模板中的日期宏须由调度器展开。生产写入前，请在目标 Hive 版本核验实际表结构、输入完整性及分区覆盖范围。
